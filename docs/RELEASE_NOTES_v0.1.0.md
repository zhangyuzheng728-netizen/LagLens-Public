# LagLens v0.1.0 — Source preview

This repository provides source code, a synthetic sample and tests. No
prebuilt LagLens Windows ZIP has been published.

- Capture local frame timings with the optional PresentMon CLI and optional
  hardware telemetry.
- Read the diagnosis, evidence and next steps in the main window. Export to
  Markdown or JSON only when needed.
- Open a sample, an existing CSV or a recent capture in the same Analysis page.
- Switch between English and Simplified Chinese.

See [how to run from source](../README.md#run-from-source).
Long recordings can take noticeably longer to open. Findings are observed
associations, not confirmed causes. Windows binary distribution is separate
from this source preview.
